# Class.pro

## External Repositories

The `_X_Pros/` folder is dedicated to external repositories that will be cloned there. Its contents are ignored via `.gitignore` and are not versioned within the `Class.pro` repository.

### `_X_Pros/Prime.pro`

**Prime.pro** is the course tutor's repository, made available to course participants. It is cloned into `_X_Pros/Prime.pro` from [https://github.com/W6-Class/Prime.pro](https://github.com/W6-Class/Prime.pro) and is not versioned within this repository.
